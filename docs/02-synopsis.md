# Project Synopsis

## Title
AI-Powered Cash Flow Forecasting and Decision Support System for SMEs

## Domain
Artificial Intelligence and Machine Learning

## Type of Project
Academic AI and Decision Support System

## Overview
This project develops an intelligent cash-flow forecasting system that helps SMEs predict future cash positions and assess financial risks. The system uses historical business data and a simple but effective Multiple Linear Regression model to estimate future cash flow. It adds explainability using SHAP, uncertainty analysis through Monte Carlo simulation, and scenario testing through What-If analysis. A rule-based recommendation engine gives practical suggestions based on forecast results, thresholds, and risk conditions.

## Problem Statement
Most SMEs do not have a structured or automated way to forecast cash flow. Without timely insight into future cash position, they may overspend, struggle with collections, or face liquidity crises. Traditional manual financial review is often slow, inconsistent, and hard to explain. There is a need for a simple but effective AI-based system that can analyze business data, explain predictions, simulate changing conditions, and suggest actions.

## Objectives
1. To collect and preprocess business financial data.
2. To forecast cash flow using Multiple Linear Regression.
3. To explain model behavior using SHAP.
4. To support business decision-making through What-If scenario analysis.
5. To estimate uncertainty using Monte Carlo simulation.
6. To provide rule-based recommendations for actions.
7. To deliver the complete solution through an interactive Streamlit dashboard.

## Methodology
The project follows a structured pipeline:

Business Data → Data Cleaning → Feature Selection → Model Training → Forecasting → SHAP Analysis → What-If Simulation → Monte Carlo Risk Estimation → Rule-Based Recommendation → Dashboard

## Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- SHAP
- Matplotlib
- Plotly
- Streamlit

## Expected Outcome
The system provides a useful academic prototype that can forecast cash flow, explain predictions, evaluate risk under different conditions, and offer actionable recommendations for SME decision-making.

## Significance
The project demonstrates practical AI usage in finance while remaining simple, understandable, and explainable. It is suitable for evaluation in a college exhibition, student project demo, or academic presentation.
