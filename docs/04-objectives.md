# Objectives

The main objectives of the project are:

1. To analyze historical business data and identify relevant financial variables such as sales, expenses, receivables, payables, and cash movements.
2. To preprocess raw financial datasets and prepare them for machine learning.
3. To build a forecasting model using Multiple Linear Regression for predicting future cash flow.
4. To evaluate the accuracy of the model using standard metrics such as MAE, RMSE, and R².
5. To explain the contribution of each feature to the forecast using SHAP.
6. To perform What-If analysis by simulating business changes and observing their effect on cash flow.
7. To estimate uncertainty in forecasts using Monte Carlo simulation.
8. To generate simple rule-based recommendations for financial decision-making.
9. To develop an interactive dashboard using Streamlit for user-friendly visualization and reporting.
10. To provide an understandable and exhibition-friendly AI/ML prototype suitable for an academic environment.

## Specific Aim
The project aims to build a complete cash flow decision support system that helps users understand what will happen, why it happens, what scenario changes may cause, and what action should be considered.
