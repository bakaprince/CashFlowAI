# Final Project Summary

The AI-Powered Cash Flow Forecasting and Decision Support System for SMEs is an academic project developed to support financial planning and risk evaluation for small and medium businesses. It combines business data preprocessing, machine learning, explainability, scenario analysis, uncertainty simulation, and recommendation generation into a single user-friendly dashboard.

The project uses Multiple Linear Regression as the forecasting model due to its simplicity, interpretability, and suitability for a college-level exhibition prototype. SHAP is used to explain how features such as sales, expenses, receivables, and payables influence the prediction. A What-If module allows users to simulate change in variables and observe their effect on future cash flow. Monte Carlo simulation is used to estimate a possible range of outcomes and display risk. Finally, a rule-based recommendation engine provides straightforward financial guidance.

The final solution is delivered through a Streamlit application that allows users to upload data, inspect financial trends, evaluate predictions, test scenarios, and interpret recommendations. The project is intentionally designed to be understandable, feasible, and exhibition-ready, while still demonstrating the complete AI workflow in a real decision-support scenario.

This project successfully demonstrates how AI and machine learning can be applied in business forecasting, explainability, and risk analysis in an academic context.
