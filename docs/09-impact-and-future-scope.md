# Impact and Future Scope

## Impact
This project demonstrates how AI can be applied in real business decision-making, especially in cash-flow planning for SMEs. It provides a simple pathway to predict future financial health and identify risks early. The project also shows how explainable AI can help users trust and understand machine learning outputs.

## Social and Industrial Relevance
The project is relevant because many small businesses lack advanced financial planning tools. A simple dashboard-based solution can help entrepreneurs manage cash position, identify risk, and make evidence-based decisions without requiring advanced technical knowledge.

## Future Scope
Although the current project is intentionally simplified, it can be expanded in the future with:

- more advanced forecasting models,
- more detailed business features,
- integration with ERP or accounting systems,
- real-time dashboards,
- multi-user and secure deployment,
- more advanced uncertainty models,
- richer recommendation logic,
- mobile-friendly interfaces.

## Academic Significance
From an academic perspective, the project highlights the complete AI workflow: data preparation, machine learning, explainability, simulation, recommendation, and deployment as an application.
